# 数据字段、质量规则和再生

示例来自 2025-06-01、02、03 的 CLK1B C/D 六份原始日文件。原始日文件有 YAML 头和 8 个数据字段；教学文件在最前面增加两个便于阅读的日期、时间字段，共 10 列。

| Python 列索引 | 内容 | 单位/解释 |
|---|---|---|
| 0、1 | 日期、时间 | 按接收机历元秒数生成，未做 UTC 转换 |
| 2 | rcv_time | 自 2000-01-01 12:00:00 起的接收机时间秒数 |
| 3 | GRACEFO_id | C 或 D |
| 4 | clock_id | 原产品字段；示例为 -1 |
| 5 | eps_time | 秒；GPS Time = rcv_time + eps_time |
| 6 | eps_err | eps_time 的形式误差，秒 |
| 7 | eps_drift | s/s |
| 8 | drift_err | s/s |
| 9 | qualflg | 二进制字符串，最右侧为 bit 0 |

预测目标为第 5 列的 eps_time；eps_drift 和形式误差不作为本版模型输入。

## 原始文件如何获得

从 [PO.DAAC 数据集合](https://podaac.jpl.nasa.gov/dataset/GRACEFO_L1B_ASCII_GRAV_JPL_RL04)进入 Earthdata Search，选择 2025-06-01 至 2025-06-03 并下载日产品（下载通常需要 Earthdata 登录）。解压后选择 `CLK1B_2025-06-DD_C_04.txt` 和 D 星对应文件，不要把 GNV1B 轨道文件当钟差文件。

下载凭据只保存在用户自己的环境中，不写入本仓库。数据集合、产品 DOI、许可证入口和致谢见 [DATA_SOURCES.md](../DATA_SOURCES.md)。

## 固定合并规则

1. 按原始日文件名中的日期升序处理。
2. 仅保留 `qualflg == 0` 的记录。这是本教学试验的保守选择：某些非零位描述日界平滑，并不普遍代表坏数据；本实验仍统一排除并报告数量。
3. 同一历元存在多条保留记录时，用最后读到的记录。因此后日文件覆盖前日重叠段；文件内后条覆盖前条。
4. 时间排序，不插值，不平滑，不对齐不同日文件的钟差偏移。
5. 生成日期标签，按原精度保留八个原始字段，并记录源文件及输出 SHA-256。

| 卫星 | 原始记录 | 删除非零标记 | 有效重复记录 | 最终记录 |
|---|---:|---:|---:|---:|
| C | 26109 | 6 | 122 | 25981 |
| D | 26084 | 10 | 123 | 25951 |

相邻日文件在同一历元的钟差会有差异。这个选择规则用于复现当前示例，不证明它适用于所有年份或实时预测。研究时应固定规则并分析其敏感性。

## 从原始日文件再生

以下路径只是示意：把三个文件放入 `data/raw`，在仓库根目录执行。输出必须指定新路径，避免覆盖附带样本。

```powershell
.\.venv\Scripts\python.exe prepare_data.py data/raw/CLK1B_2025-06-01_C_04.txt data/raw/CLK1B_2025-06-02_C_04.txt data/raw/CLK1B_2025-06-03_C_04.txt --satellite C --output data/rebuilt/CLK1B_2025-06-01_to_2025-06-03_C.txt
```

把命令中的 C 全部改为 D，生成 D 星文件，然后：

```powershell
.\.venv\Scripts\python.exe experiment.py --data-dir data/rebuilt --output-dir outputs/rebuilt
```

源产品可能重新发布。先比较 manifest 的原始文件 SHA-256；相同文件和规则应得到相同输出哈希，源文件变化时不要强行对齐旧结果。

## 已知缺口和钟跳

D 星 2025-06-02 23:04:50 至 23:09:40 相隔 290 s，伴随约 +10.208 ms 的钟差变化；随后还有一个 30 s 间隔。本实验不跨越缺口插值，D 星 6 月 3 日 00:00 的计划窗口被排除，排除理由保存在输出 JSON。所有时刻均为接收机时间标签。

`make_windows` 同时检查历史和评价区间的完整性，定义了离线评价样本。`forecast.py` 只检查已知历史，不能预测未来是否会发生钟跳或缺测。
