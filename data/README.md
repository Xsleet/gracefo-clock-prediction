# 这个小数据文件是什么

`clock.csv` 是 GRACE-FO C 星的一段真实钟差，共 2520 行、两列：

| 列名 | 含义 |
|---|---|
| `receiver_seconds` | 自 2000-01-01 12:00:00 起的接收机时间秒数，不是 UTC |
| `clock_seconds` | CLK1B 的 eps_time，单位为秒；GPS Time = receiver time + eps_time |

每 10 秒一条。前 2160 行是历史，后 360 行用于评价预测。

- 历史：2025-06-01 18:00:10 至 2025-06-02 00:00:00。
- 未来：2025-06-02 00:00:10 至 01:00:00。
- 上述日期均按接收机时标解释；名义 6 h 历史的首末跨度为 5 h 59 min 50 s。
- 固定使用原完整实验的第一个 C 星窗口，没有按误差挑选。

文件取自 `sample/CLK1B_2025-06-01_to_2025-06-03_C.txt` 的第 3 列（历元秒数）和第 6 列（eps_time），不改变其数值。此窗口没有缺测、非零质量标记或 clock_id 变化。

`sample/` 保存原来的三天 C/D 数据和六份原始日文件的哈希清单；详细合并规则见 [完整数据说明](../advanced/docs/data.md)，原始来源与引用见 [DATA_SOURCES.md](../DATA_SOURCES.md)。`example.png` 为本次固定窗口在 GPU 上实际运行的结果图：上方展示历史观测与未来预报，下方展示未来误差。
